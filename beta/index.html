MIDI Conductor 0.7 beta

A test version for a few people before the next release. It is built on DOOM OS 0.7 and brings MIDI tracks, MIDI FX, a new device setup and a lot more. Thank you for trying it.

Beta, experimental. Modified firmware can brick your SP-404MKII. This build is tested on one unit only. Back up your SD card and projects first, and keep Roland's original 5.52 files so you can go back.

What's new since 0.6

  • DOOM OS 0.7 underneath.
  • MIDI tracks: pick MIDI in DOOM OS's instrument picker and a pad plays your synth, with its own page to choose the synth. The old PADS screen is gone.
  • Devices: new DEVICES screens with names, CC names, INPUT ONLY and USAGE, and a DEVICES.CSV file to bring your synths in (make it below).
  • MIDI FX: eleven effects on each MIDI or GHOST track (Harmonize, Echo, Scale, Chance, Randomize, Dispatch, Euclid, Loop Stretch, LFO, ENV, Time Elastic), the CHAIN page to switch, reorder and route them.
  • The CC MAP: ranges, and a synth's dials can move a track's mixer, its MIDI FX and its EQ.
  • GHOST: programs, and it follows DOOM OS's mixer and EQ.
  • Per project: your devices, routes, CTRLs and MIDI tracks belong to each project.
  • Recording dial moves is now MARK + REC. MARK held is catch on every screen.

The beta manual covers all of it.

1. Patch

Drop SP404MKII_APP1.bin from Roland's 5.52 update below: Roland's own file, not a DOOM OS one or an earlier MIDI Conductor. It runs in your browser and nothing is uploaded.

2. Your synths

Synths are no longer built into the firmware. Pick yours here, download DEVICES.CSV and load it on the SP. You can make a new one at any time without patching again.

    Up to six synths, as devices 1 to 6 in the order shown (device 7 is GHOST). The file holds their names and CC names; set each device's MIDI channel on the SP afterwards.

    1. Copy DEVICES.CSV to the top level of the SD card, next to the IMPORT and EXPORT folders.
    2. On the SP: SHIFT + REMAIN, open DEVICES, press MARK, pick IMPORT and press VALUE. Turn VALUE to YES and press it.
    3. Still on DEVICES, turn VALUE to each device and set its channel with CTRL 3.

    The devices belong to the project you import them into. For another project, import the file there too.

    3. Install

    Download the patched SP404MKII_APP1.bin and keep that name. Install it with Roland's original SP404MKII_APP0.bin, the same way as DOOM OS (DOOM OS manual). To go back, install Roland's original files, or a release from the current patcher.

    Coming from 0.6: your devices, routes and CTRLs move into the first project the SP starts in. Pads you set on the old PADS screen are cleared after a few seconds; make them again as MIDI tracks (see the manual).

    4. Testing

    Everything new is worth a go. The parts that most need real hands on them:

    • MIDI tracks: making them, picking the synth, deleting them, and the notes they send from the pattern.
    • MIDI FX on your synths and on GHOST, the CHAIN page (moving effects, SOURCE PAD), and recording dial moves with MARK + REC.
    • Importing DEVICES.CSV, and switching between projects.
    • The CC MAP from a controller to your synths and to the SP's mixer, MIDI FX and EQ.

    Known: the Arp is left out of MIDI FX in this beta while it is reworked. GHOST's device shows its channel as CH 17.

    When something goes wrong, note what you pressed and what you expected, and send it over with a photo or video of the screen if you can.
