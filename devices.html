Your synths on the SP

Make DEVICES.CSV, the file the SP reads your synths from: names, CC names and channels. Use it to change your synths without patching again. It runs in your browser and nothing is uploaded.

1. Pick your synths

Already have a JSON or CSV file?

Drop a CC list you made for the patcher and its synths join the list above. A device-numbered JSON (see the JSON) goes straight to DEVICES.CSV.

    Up to six synths, as devices 1 to 6 in the order shown (device 7 is GHOST). The file holds their names, CC names and, when your list gives one, their MIDI channel: the SP puts each device on that channel when it imports.

    2. Put it on the card

    1. Copy DEVICES.CSV to the top level of the SD card, next to the IMPORT and EXPORT folders.
    2. On the SP: SHIFT + REMAIN, open DEVICES, press MARK, pick IMPORT and press VALUE. Turn VALUE to YES and press it. Every device in the file is replaced; the others stay as they are.
    3. Check each device's channel on DEVICES. One the file had no channel for shows NO CH and isn't offered to a CTRL or a MIDI Instrument yet: turn VALUE to it and set its channel with CTRL 3.

    The devices belong to the project you import them into. For another project, import the file there too. EXPORT on the same screen writes the project's devices back to the card.

    The JSON

    {
  "devices": [
    {
      "device": 1,
      "name": "MS-20",
      "input_only": false,
      "raw_ccs": "show",
      "ccs": [
        {"cc": 74, "name": "CUTOFF"},
        {"cc": 71, "name": "RESO"}
      ]
    }
  ]
}

    Only device is needed. raw_ccs is "show" or "hide" (the CTRL dials reach every CC, or only the named ones). Names use A to Z, 0 to 9, space, - and ., up to 7 characters. ccs can also be a list of [cc, "name"] pairs or an object like {"74": "CUTOFF"}.
