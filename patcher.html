1. Patch

Drop SP404MKII_APP1.bin from Roland's 5.52 update below: Roland's own file, not a DOOM OS one. Under CC lists, add your synths so the SP knows their controls by name. Skip it and the dials use CC numbers.

2. Install

Download the patched SP404MKII_APP1.bin and keep that name. Install it with Roland's original SP404MKII_APP0.bin, the same way as DOOM OS (DOOM OS manual). To go back, install Roland's original files.

3. Play

The quick start puts a synth on a pad and a dial in five steps.

Experimental. Modified firmware can brick your SP-404MKII. This is tested on one unit only, and it hooks some of Roland's own routines, which the DOOM OS author has called risky. Keep Roland's original files so you can go back.
