1. Patch

Drop SP404MKII_APP1.bin from Roland's 5.52 update below: Roland's own file, not a DOOM OS one or an earlier MIDI Conductor. Under CC lists, add your synths so the SP knows their controls by name. Skip it and the dials use CC numbers.

You can change your synths later without patching again: make a DEVICES.CSV on the devices page and import it on the SP.

2. Install

Download the patched SP404MKII_APP1.bin and keep that name. Install it the same way as DOOM OS (DOOM OS manual). To go back, install Roland's original files.

Coming from 0.6: your devices, routes and CTRLs move into the first project the SP starts in. Pads you set on the old PADS screen are cleared after a few seconds; make them again as MIDI Instruments. See the changelog for everything that's new.

3. Play

The quick start puts a synth on a pad and a dial in six steps.

The 0.6.5 quick start puts a synth on a pad and a dial in five steps.

Experimental. Modified firmware can brick your SP-404MKII. This is tested on one unit only, and it hooks some of Roland's own routines, which the DOOM OS author has called risky. Back up your SD card and keep Roland's original files so you can go back.
